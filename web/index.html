Features

mGBA Core

Built on the advanced mGBA core for excellent game compatibility. Run almost any GBA game with ease, and share save states with the desktop version of mGBA.

Fast-forward with Normal-speed Audio

Speed up your gameplay while keeping audio at its normal playback speed. Enjoy faster progress without speeding up the original game audio, for a more comfortable and natural experience.

Load Games with Ease

A clean, intuitive, and thoughtfully designed interface. Load ROMs directly from ZIP, RAR, and 7z archives.

Controls Your Way

Customize the position, size, and style of on-screen buttons, map physical controllers, and add your own background images.

Handy Built-in Tools

Take screenshots, use cheat codes, and inspect game state with tools built right into the app.

Play with Friends

Connect locally or remotely to enjoy more ways to play games that support multiplayer.
